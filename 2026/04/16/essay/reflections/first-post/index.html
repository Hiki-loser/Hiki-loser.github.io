写在开头

这是我的博客的第一篇文章。

起因是在我们学校的某厂的一个招聘宣讲会，然后莫名其妙地投递了简历，也收到了面试通知，然后就被面试官拷打了。

我的手撕 Java 多线程和 SQL 多表查询和一个关于链表的算法题都没写出来，反问环节我询问他现在学习这些基础有啥用，反正都有 AI 了，我只把这些基础当成是我通向实习和 offer 的门票。

他说，还是有用的，可以增加自己的逻辑什么的。

反正很可惜，没有通过。所以我决定重新学习一下计算机基础知识，也决定建立这个博客。后期打算扩展成真正的一个网站，能评论什么的，也会写一些我学习的技术总结或者随笔。
